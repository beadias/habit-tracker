# Sistema de Gestão de Hábitos 

Sistema full stack desenvolvido para gerenciamento de hábitos diários e semanais, permitindo cadastrar, editar, excluir e acompanhar o progresso diário dos hábitos.

---

# Funcionalidades

- Cadastro de hábitos
- Edição de hábitos
- Exclusão de hábitos
- Registro de progresso diário
- Histórico de registros
- Barra de progresso
- Porcentagem de conclusão
- Hábitos diários e semanais

---

# Tecnologias utilizadas

## Front-end
- HTML
- CSS
- JavaScript

## Back-end
- Node.js
- Express

## Banco de dados
- PostgreSQL
